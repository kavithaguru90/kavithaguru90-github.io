# Prompt 1- What emerging technology did you choose? How is AI being used to support this technology

## Cloud Data Platforms (Snowflake,Databricks)- Relevant to Data engineering 

Cloud data platforms are becoming more intelligent through the integration of Artificial Intelligence (AI).
### Automates Data Analysis
 AI analyzes large datasets to identify patterns, trends, and anomalies quickly.

### Enables Natural Language Queries
 Users can ask questions in plain English, and AI converts them into SQL queries.

### Improves Data Quality
 AI detects missing values, duplicate records, and data inconsistencies automatically.

### Provides Predictive Insights
 AI uses historical data to forecast trends, customer behavior, and business outcomes.

### Monitors Data Pipelines
 AI identifies pipeline failures, delays, and performance issues before they impact users.

### Enhances Productivity
 Tools like Microsoft Copilot, Snowflake Cortex, and Databricks AI Assistant help generate code, documentation, and troubleshooting recommendations.

### Dashboards
 Create dashboards using the data context.

 # Prompt 2 - What previous solutions were being used in place of AI? How has AI replaced or will soon replace these solutions?

 ## Previous Solutions Before AI

Before AI, organizations relied on manual and rule-based approaches:
- Data analysts manually reviewed reports and dashboards.
- Engineers wrote complex SQL queries to answer business questions.
- Data quality checks were created using fixed validation rules.
- Pipeline monitoring depended on manual log reviews and alerts.
- Forecasting was performed using spreadsheets and traditional statistical models.
- Documentation and code development were completed manually.

## How AI Replaces or Enhances These Solutions

| Traditional Approach | AI-Driven Approach |
|---------------------|-------------------|
| Manual data analysis | Automated pattern and anomaly detection |
| Complex SQL queries | Natural language querying |
| Rule-based validations | Intelligent data quality monitoring |
| Manual pipeline monitoring | Predictive issue detection |
| Spreadsheet forecasting | Machine learning predictions |
| Manual coding and documentation | AI-assisted code and document generation |
